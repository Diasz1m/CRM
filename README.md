# CRM

CRM com gerenciamento de leads, catálogo de produtos e relatório de leads por período.

## Projetos

- [crm-backend](crm-backend/README.md) contém a API em Java 25 e Spring Boot, autenticação de administrador, gerenciamento de leads e produtos e migrações PostgreSQL com Flyway.
- [crm-frontend](crm-frontend/README.md) contém o painel em Vue 3, TypeScript e Vite, com login e telas de leads e produtos.
- [crm-reports](crm-reports/README.md) contém o microserviço Spring Boot de relatórios. consulta contagens por etapa através da API interna do backend.
